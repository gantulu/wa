# Project Structure Baseline

Repository: `gantulu/wa`

This document records the directory and ownership baseline established in Phase 00A.

## Source of truth

- `public/`: static public files copied into the production output.
- `pages/`: HTML page entry documents.
- `src/`: application source (assets, CSS, and modular JavaScript).
- `scripts/`: project build and maintenance scripts.
- `tests/`: unit, integration, and end-to-end test suites.
- `docs/`: architecture and operational documentation.
- `.github/workflows/`: repository automation definitions.

## Generated output

- `dist/` is generated by the build process.
- `dist/` is not a source directory and must not be manually maintained as the canonical implementation.
- The generated output is intended for GitHub Pages publication.

## Phase boundary

Phase 00A establishes repository identity, the `main` branch, this structural scaffold, and the initial commit history. Project tooling and runnable build configuration belong to Phase 00B.

## Deployment path constraint

The eventual GitHub Pages deployment is expected at `https://gantulu.github.io/wa/`. Source and build configuration must preserve the `/wa/` base path in later phases.
